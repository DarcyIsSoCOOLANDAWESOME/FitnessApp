# Fitness App

## Basic Idea

- The user can sign up for a fitness app with a username, email and password.
- The user can login using their email and password.
- Username ID is linked to email ID
- Password is linked to email and user ID's

- User can search exercises based on an API, eg can search through "legs" filter and Squat exercise will come up.
- On the exercises user can input data based on recent exercises. KG, reps and sets and the date.

- The exercises automatically put your PB on based on inputted data
- The user can put a goal weight and reps (not sets, this would be too complicated to add total loaded KG during exercise, so i will just do it by weight and reps)
